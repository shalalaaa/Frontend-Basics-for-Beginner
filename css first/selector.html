Selector Tags

We're going to talk about many selectors that are used in CSS, but not all of them because we would get to know about them as we do projects. Most of them are not useful all the time.

  1. Element Selector

    Matches all HTML elements of a specific tag name, such as p, h1, or div. 

                Syntax:
            h2 {
                background-color: rgb(198, 251, 233);
                color: rgb(1, 1, 70);
            }

  2. Class Selector

    Matches every element that has a specific class attribute value. 

                Syntax:
            .unique {
                color: rgb(125, 6, 138);
            }

  3. ID Selector

    Matches the single, unique element on the page with a specific ID attribute. 

                Syntax:
            #pre {
                color: rgb(110, 2, 2);
            }

  4. Child Selector

    The child combinator (>) selects only the elements that are direct children of a specified parent element. 

                Syntax:
            li > p {
                color: rgb(0, 102, 0);
            }

  5. Descendant Selector

    Matches any element B that is nested anywhere inside element A. 

                Syntax:
            div p {
                color: rgb(132, 5, 250);
            }

  6. Pseudo-classes

    Pseudo-classes select elements based on a special state, user interaction, or their position in the document tree. 

                Syntax:
            a:link {
                color: green;
            }

            a:visited {
                color: yellow;
            }

            a:hover {
                color: purple;
                background-color: lightgray;
            }

            a:active {
                color: red;
            }
