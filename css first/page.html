Three Ways to Add CSS to an HTML File

  1. Inline CSS
  2. Internal CSS
  3. External CSS

We're going to learn about all three ways of adding CSS to an HTML file.

Inline CSS is not generally recommended because we have to add CSS separately to every HTML element we want to style.

  1. Inline CSS:

    2. <h1 style="color: red; background-color: pink;">
    This is Inline CSS
</h1>

    Inline CSS is one way of adding CSS directly inside an HTML element using the style attribute. However, it is not generally considered good practice.

  2. Internal CSS:

    3. <style>
    div, span {
        color: brown;
        background-color: bisque;
    }

    p {
        color: pink;
        background-color: magenta;
    }
</style>

    In general, using internal CSS is not a good practice for full websites, though it is ideal for a few specific scenarios.

  3. External CSS:

    4. <link rel="stylesheet" href="styles.css">

    External CSS stores styling rules in a separate .css file linked to HTML pages, making it easy to maintain consistent designs across multiple pages.

    It is generally the best choice for multi-page websites because it reduces code repetition and allows browsers to cache the CSS file.
