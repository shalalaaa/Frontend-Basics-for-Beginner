Semantic Tags

What are Semantic Tags?

Semantic HTML is not just about readability; it gives meaningful structure to web content so browsers, search engines, and assistive technologies can better understand it.

Why Use Semantic Tags?

They enhance SEO, improve accessibility, and make your code easier to read and maintain.

Keys of Semantic Tags

  • <header>: Used to represent the introductory section of a web page.
  • <nav>: Signifies a navigation menu on a web page.
  • <article>: Indicates a self-contained piece of content, such as a blog post or news article.
  • <section>: Represents a thematic grouping of content.
  • <aside>: Used for content that is related but separate from the main content.
  • <footer>: Represents the footer of a web page.
  • <figure> and <figcaption>: Used for images, diagrams, or charts with captions.
  • <main>: Signifies the main content area of a web page.
  • <time>: Represents time-related information, like dates and times.
